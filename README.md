# Heartaker

Cinematic, evidence-informed films for the people who care for other people.

## Current production

**“10 Best Tips to Deal with Alzheimer’s”** — a 2:04 cinematic caregiver film
(1920×1080, 30 fps) with an original score, ten chapters and a shareable end
card.

- Film, captions, thumbnail and poster: [`video/out/`](video/out/)
- Production notes, structure and re-render instructions: [`video/README.md`](video/README.md)
- Renderer, copy deck and score generator: [`video/scripts/`](video/scripts/)

The score in `video/audio/score.wav` is synthesized from scratch by
`video/scripts/audio.py` — no samples, no library license, no attribution
required.
